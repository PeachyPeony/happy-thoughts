# Happy Thoughts 
A React application where users can share happy thoughts and spread positivity by liking messages.

## Features
- Fetch and display thoughts from an API
- Display the newest thought first
- Create and submit new happy thoughts
- Like thoughts and display their heart counts
- Show how long ago each thought was posted
- Responsive design for mobile, tablet and desktop

## Built With
- React
- JavaScript
- HTML5
- CSS3
- Vite
- Happy Thoughts API
